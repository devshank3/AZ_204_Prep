# Secure APIs in API Management

## Subscriptions and Keys

A **subscription key** is a unique, autogenerated key passed in request headers or as a query string parameter. It is tied to a **subscription**, which controls permissions and policies.

### Subscription Scopes

| Scope | Details |
|---|---|
| **All APIs** | Applies to every API accessible from the gateway |
| **Single API** | Applies to one imported API and all its endpoints |
| **Product** | Applies to a collection of one or more APIs with shared access rules, quotas, and terms of use |

- APIs can belong to more than one product
- **Protected APIs require the key in every request**
